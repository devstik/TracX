OBJETIVO

Quando o usuario bipar a mesma OP + mesmo artigo no mesmo check-in,
nao deve bloquear nem criar nova linha.

Deve atualizar a linha existente assim:

- quantidade_tambores = quantidade_tambores + nova quantidade
- volume permanece o mesmo, porque o volume da mesma OP/artigo deve contar uma vez

2) ALTERAR O RECALCULO DOS TOTAIS NA API
======================================================================

Na funcao:

def _recalcular_totais_checkin_tambores(cursor, id_checkin_tambores):

use:

SELECT
    ISNULL(SUM(i.quantidade_tambores), 0) AS quantidade_tambores,
    ISNULL(SUM(i.volume), 0) AS volume_total
FROM dbo.checkin_tambores_itens i
WHERE i.id_checkin_tambores = c.id_checkin_tambores

Importante:
Como cada OP/artigo fica em apenas uma linha, SUM(volume) nao duplica o volume
quando o usuario bipa a mesma OP/artigo varias vezes.

6) ALTERAR OS SELECTS DOS ITENS
======================================================================

Em todos os SELECTs de dbo.checkin_tambores_itens, adicione:

quantidade_tambores

Exemplo:

SELECT
    id_checkin_tambores_item,
    id_checkin_tambores,
    codigo_tambor,
    volume,
    bipado_em,
    ordem_producao,
    artigo,
    quantidade_tambores
FROM dbo.checkin_tambores_itens


Na rota /itens/resumo, troque:

quantidade_tambores = COUNT(*)

por:

quantidade_tambores = ISNULL(SUM(quantidade_tambores), 0)

RESULTADO
======================================================================

Antes:

OP 189813 + CLEIDE 4 30 MM RATS bipada 3 vezes podia bloquear,
criar duplicado ou somar volume indevidamente.

Depois:

1 linha no SQL:

ordem_producao: 189813
artigo: CLEIDE 4 30 MM RATS
quantidade_tambores: 3
volume: volume da OP/artigo apenas uma vez
